검토일: 2026-11-07

## 범위와 방법

- 이 작업은 공식 상품설명서 PDF, 기존 PostgreSQL read-only snapshot, 기존 Neo4j read-only snapshot 및 기존 추출 기록만 대조했다.
- Streamlit/GraphRAG 질문 실행, LLM API, DB 쓰기, 애플리케이션 코드 변경은 하지 않았다.
- 스캔형 PDF는 관련 페이지를 렌더링해 표의 행·열을 눈으로 확인하고, 텍스트 추출이 가능한 PDF는 원문 추출 텍스트도 대조했다.
- `VERIFIED`는 평가 정답 사실이 공식 PDF에서 직접 확인되었다는 뜻이다. PostgreSQL 승인 상태나 Neo4j Evidence 연결이 완전하다는 의미가 아니다.

## 정합성 요약과 사람 확인 필요 항목

- 정답 상태: **VERIFIED 49 / NEEDS_REVIEW 1 / NOT_IN_SOURCE 0**.
- 유일한 NEEDS_REVIEW는 CARD10-030이다. 공식 PDF 자체에서 특정 알뜰폰 사업자는 대상 목록에 포함하면서 알뜰폰 요금은 제외한다고 함께 적어 적용 범위가 충돌한다. 상품 담당자 또는 카드사 원문 확인이 필요하다.
- PDF 정답은 VERIFIED이나 원장/Neo4j 연결이 미완성인 항목: CARD10-020 (연회비 item/Evidence 부재), CARD10-026 (세부 제휴주차장 안내 별도), CARD10-038 (3만원/50만원 조건 Evidence link 부재), CARD10-058 (추가적립 item/Evidence 관계 미확인), CARD10-059 (바우처 혜택 소유 Evidence 관계 미확인).
- OCR 보정 확인이 필요한 Evidence 연결: CARD10-039 Evidence 002769/002770. PDF 이미지로 정답은 검증했지만 원장 원문/Neo4j Evidence의 정제 상태를 별도 정리해야 한다.
- 데이터베이스의 `PENDING_REVIEW` 상태는 변경하지 않았다. PDF 정답 검증과 DB 승인/정합성 상태는 서로 다른 축이다.

## 변경 범위와 무결성

- 수정한 파일은 `golden_answer_set_50.json`, `golden_answer_set_50.md`, `golden_answer_review.md`뿐이다.
- 질문 집합(`evaluation_set_50.json`), 질문 ID, 질문 문구, hop 분류, PostgreSQL, Neo4j, 애플리케이션 코드는 변경하지 않았다.
- 평가 생성물은 기존 평가 자료이며 실제 GraphRAG 출력이 아니다.
