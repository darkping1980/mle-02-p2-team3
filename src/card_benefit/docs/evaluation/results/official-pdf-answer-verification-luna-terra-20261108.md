## 해석 및 한계

- 이 자료는 두 실행 파일에 이미 저장된 답변을 평가한 것이며 LLM 실행 추적 재구성이 아니다. PDF/페이지는 실행 JSON의 출처 메타데이터와 실제 로컬 공식 PDF를 연결했다.
- 표가 있는 쪽은 렌더링 이미지로 혜택명, 대상 열, 금액/한도 행의 소속을 확인했다. PDF text extraction만으로 행·열 소속이 불명확한 곳은 이미지 확인을 우선했다.
- PDF 파일은 로컬 원본과 평가 메타데이터의 SHA-256이 일치했다. 다만 발급사 웹사이트에서 현재 공개 중인지 여부는 별도 확인하지 않았다.
- 실행 결과의 Golden ID 범위가 뒤 10개에서 10개 밀려 있다. 내용이 비슷하더라도 대체 ID로 매칭하지 않았다.
- 채점은 CORRECT/PARTIAL 중심으로 보수적으로 수행했다. 확정 가능한 핵심 사실 오류가 확인된 문항은 없었고, 누락된 답변은 NO_ANSWER로 분리했다. PARTIAL은 오답 수와 섞지 않는다.
