## 우선 검토 1 — 06페이지: 표 추출의 실제 어려움

현재 '공식 근거' 항목은 발생한 문제라기보다 해결 방향에 가깝습니다. 다음처럼 바꾸면 다른 세 항목과 표현 목적이 일치합니다.

| 항목 | 수정 문구 초안 |
|---|---|
| 서식 차이 | 카드마다 표 구성과 혜택 설명 방식이 달라 동일한 방식으로 추출하기 어려웠음 |
| 표 추출 | 병합 셀과 복잡한 표 구조 때문에 추출 결과가 누락되거나 잘못 구분되는 경우가 있었음 |
| 조건 연결 | 혜택과 전월 실적·할인 한도·제외 조건이 추출 과정에서 분리되어 관계를 확인하기 어려웠음 |
| 원문 대조 | 추출된 내용만으로 정확성을 판단하기 어려워 PDF 원문과의 대조가 필요했음 |

**하단 문구 수정 초안**  
단순한 텍스트 추출을 넘어, 혜택·조건·원문 근거의 관계를 정확하게 연결하는 것이 과제
