## 슬라이드 16/17 — LangGraph 기반 질문 처리 흐름

**구분:** 기술 구현 03  
**제목:** LangGraph 기반 질문 처리 흐름

**실행 흐름**

`Streamlit 사용자 질문 → interpret → retrieve → answer → finish → Streamlit 결과 표시`

| 단계 | 역할 | 주요 처리 |
|---|---|---|
| 01. `interpret` | 질문 해석 | Neo4j 후보 검색 및 LLM으로 질문 의도·대상 혜택 선택 |
| 02. `retrieve` | 근거 조회 | 정해진 Cypher로 혜택·조건·PDF 원문 근거 수집 |
| 03. `answer` | 답변 생성 | 조회한 혜택·PDF 근거를 바탕으로 LLM 답변 생성 |
| 04. `finish` | 결과 정리 | 답변·오류·실행 경로를 정리해 최종 상태 반환 |

**조건부 분기**  
대상 혜택이 없거나 오류가 있으면 `interpret → finish`, 조회 근거가 없으면 `retrieve → finish`로 이동

**슬라이드 설명 문구**  
LLM이 사용자 질문을 해석합니다. Neo4j에서 혜택과 PDF 근거를 조회한 뒤, 그 근거를 바탕으로 LLM이 답변을 생성합니다.

**하단 핵심 메시지**  
Neo4j는 혜택·근거를 검색하고, LangGraph는 질문 처리의 순서와 분기를 관리합니다.
